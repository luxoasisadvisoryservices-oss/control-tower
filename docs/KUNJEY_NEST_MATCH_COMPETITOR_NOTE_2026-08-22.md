# Kunjey / Kunjey Exchange Competitor Note

Created: 2026-08-22 21:44 Dubai  
Source checked: `https://kunjey.com`, `https://kunjey.com/exchange`, `https://kunjey.com/exchange/pricing`

## Verdict

Kunjey homepage is mainly a vacation-rental PMS / channel-manager product, but Kunjey Exchange directly overlaps with the Nest Match Inventory Board / B2B network idea.

It is not a full Nest Match clone, but it is the closest local UAE B2B accommodation-network competitor found so far.

## What Kunjey Claims

- KMS: property management system for bookings, operations, financials, guest experience, marketing, team management, owner reporting and marketplace.
- Free forever base PMS, paid per connected OTA property.
- Kunjey Pro: OTA sync, unified inbox including WhatsApp, OTA messaging automation, revenue automation, dynamic-pricing integrations, API connectivity, AI assistant, analytics.
- Kunjey Exchange: UAE B2B accommodation network for verified operators, brokers, corporate housing and relocation companies.
- Exchange workflow: company verification, inventory publishing, live/iCal inventory, search/matched demand, structured offers, minimum-price protection, Kunjey Inbox, confirmation.
- Exchange features: live inventory search, secure negotiation, client proposal builder, property viewings, orphan-night promotion, connected inbox, verified-partner reputation.
- Pricing: founding phase free, no booking commission, credit system for booking requests, negotiations, private inventory requirements and gap boosts.

## Direct Overlap With Nest Match

High overlap:

- B2B accommodation network.
- Verified companies.
- Live inventory.
- Operators and brokers.
- Gap/orphan-night promotion.
- Structured requests and negotiations.
- Private inventory requirements.
- Credits as marketplace currency.
- UAE founding phase positioning.

Medium overlap:

- Messaging/inbox.
- Reputation/response time.
- Client proposal PDFs.
- Corporate/relocation demand.

Lower overlap:

- Service-provider directory.
- Freelancers/vendors.
- Contracts/checklists hub.
- Landlord/owner/operator matching beyond accommodation inventory.
- Wider STR ecosystem network.

## Threat To Nest Match

Threat level: 7/10 for Inventory Board / live B2B accommodation exchange.

Kunjey is a serious reference because it has named the exact pain: unused leads, vacant nights, B2B inventory, verified partners and WhatsApp replacement.

But Nest Match still has a different possible wedge:

- broader Dubai STR operator ecosystem, not only accommodation inventory;
- owners/landlords, agents, operators and service providers in one network;
- vendor/service-provider discovery;
- Contracts Hub / checklists;
- public directory and content loop;
- founder/operator network around Lux Oasis Advisory, not PMS-first.

## Strategic Implication

Nest Match should not describe itself only as "live inventory exchange" or "orphan-night marketplace"; Kunjey is already using that territory strongly.

Better Nest Match position:

The Dubai STR operator network: inventory, trusted intros, service partners and operator-safe contract checklists in one place.

Inventory Board remains core, but it should sit inside a wider operator network. Service providers, agents, owners/landlords and contract/checklist support become more important differentiators.

## Action

- Treat Kunjey Exchange as a direct competitor/reference for Nest Match Inventory Board.
- Study their credit model, hidden-minimum negotiation, trade-licence verification and gap-night boost.
- Do not copy their PMS-first positioning.
- Keep Nest Match focused on operator network + service-provider marketplace + contracts/checklists + inventory board.
