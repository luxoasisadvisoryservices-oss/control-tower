# Nest Match Week 1 Service Provider Outreach Plan

Created: 2026-08-31  
Period: Monday 31 August to Sunday 6 September 2026  
Channel: LinkedIn led, WhatsApp fallback  
Status: Internal plan and approval-ready workflow. No external outreach sent.

## Objective

Seed Nest Match with real service-provider profiles before operators, agents or landlords are invited.

Week 1 target:

- 30 providers approached.
- 15 live, verified provider profiles.
- At least 8 different service categories represented.
- Main metric: live profiles, not outreach volume.

## Scope Rule

One segment only this week: service providers.

Do not start operators, agents or landlords until the directory has real companies in it. The honest market message is that Nest Match is live but early, and we are filling it deliberately with the companies that actually do the work before operator launch.

1. Walk provider registration end to end.
   - Use Oasis Revenue Lab only as a test profile.
   - If it stays visible, disclose common ownership.
   - Otherwise set the ORL profile to draft after testing.
   - Record every unclear field, hesitation and slow step.

2. Fix the multi-category provider problem.
   - Required: one primary category plus two additional categories.
   - If not fixed this week, tell providers multi-category is coming and record their extra categories manually.

3. Fix Damiano's LinkedIn profile before using it for outreach.
   - Headline: `Founder, Nest Match. B2B property network for Dubai. Also running Lux Oasis Holiday Homes.`
   - Featured: pin `nest-match.com` first.
   - About: first two visible lines explain what Nest Match is and who it is for.

4. Sort providers into tiers.
   - Tier A: providers Lux Oasis currently pays. WhatsApp first, LinkedIn second. Expected conversion 70-80%.
   - Tier B: providers used before or recommended. WhatsApp or LinkedIn. Expected conversion 40-50%.
   - Tier C: companies known but not used. LinkedIn only. Expected conversion 15-20%.
